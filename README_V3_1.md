# Creative Web Intelligence Library v3.1

**Production Hardening Edition.** This package contains all v3.0 capabilities and adds a substantially deeper backend/security, typography and scroll intelligence layer.

## What changed

### Backend / security
The library now treats secret management, authorization, encryption decisions, data classification, API contracts, uploads, SSRF boundaries, webhooks, idempotency, logging/redaction, migrations/backups and deployment as first-class architecture decisions.

Important: **API keys cannot be made secret inside browser code.** Privileged credentials must live on a trusted backend/runtime/secret store. Passwords are hashed rather than reversibly encrypted.

### Typography
Typography now includes role-based systems, real-content wrap testing, variable-font axes, fallback metric/CLS strategy, multilingual glyph coverage, loading/subsetting, kinetic type policy and 200 machine-readable system recipes plus 120 pairing strategies.

### Scroll
Scroll now uses explicit chapter state machines and handoffs. v3.1 adds 160 precision choreography recipes and dedicated mobile/reduced-motion/performance rules on top of earlier v2/v3 scroll coverage.

### QA
Security, typography and scroll each have 120–160 dedicated machine-readable checks, plus the existing visual/fidelity/performance QA layers.
