# Creative Web Intelligence Library v3.0 — Full‑Stack + Motion + Reference Recreation

v3.0 extends the existing Creative Web Intelligence Library without replacing its typography, color, composition, motion, 3D, research and anti-generic systems.

## What v3 adds

- **Advanced Scroll Choreography Engine** — 120 additional recipes, motion tokens, section state machines, pin/scrub/media/3D/mobile fallbacks and implementation gates.
- **Reference Recreation Engine** — image/video → reference profile → geometry/motion breakdown → independent implementation → screenshot/video comparison loop.
- **Backend Intelligence** — architecture selection, API contracts, auth/session/RBAC, validation, databases, caching, uploads, email, queues, realtime, webhooks, security, observability and deployment recipes.
- **Full‑Stack Composer** — one decision pipeline that combines creative design, motion, backend, data and runtime requirements.
- **Visual Regression & Fidelity QA** — viewport matrices, screenshot capture, frame maps, diff manifests and human-review checkpoints.
- **Media Pipeline Intelligence** — image/video loading, responsive assets, posters, lazy decode, sequencing and performance budgets.
- **Windows Agent Workflow** — practical PowerShell-oriented setup for Claude Code/Codex style agents.

## The core principle

This is an **intelligence/reuse library**, not a site template and not a giant UI kit.

For each project, the agent should:

1. understand the brief and references,
2. build a design/reference DNA,
3. choose a dominant composition + motion language,
4. decide whether backend is actually required,
5. compose a machine-readable build spec,
6. implement independently,
7. run responsive/accessibility/performance/security/fidelity QA,
8. only then polish.

## Reference recreation rule

When the user supplies an image/video/reference, the agent may target **pixel-close / behavior-close recreation using independently written code**. Do not copy proprietary source code, hidden assets, licensed fonts, protected text, logos or media unless the user has rights to use them. If rights are unclear, preserve geometry/motion behavior while substituting neutral assets/content.
