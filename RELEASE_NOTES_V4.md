# Release Notes — v4.0

Released 2026-09-12.

v4 changes the library from a closed recipe corpus into a controlled **source-aware design intelligence system**. The library can query approved public metadata APIs for icon/font discovery, while refusing generic scraping of restricted sources.

It also establishes icon art direction as a first-class discipline: necessity, family voice, optical alignment, stroke consistency, state variants, motion purpose and provenance are evaluated before implementation.
