## Important limitation
No honest system can claim to have “watched all of YouTube and Instagram.” Instagram also blocks full automated playback of many Reels. This library instead uses a broad research pass plus an explicit capture queue. User-supplied screenshots/screen recordings can be added later for frame-level analysis.
