# Creative Web Intelligence Library v6 — Cinematic Media + 3D Web Intelligence

v6 extends the library's vocabulary from HTML/CSS/typography/icons/static-images to **every visual medium**: generated imagery, video, frame sequences, 3D, shaders, procedural graphics. Most importantly, it teaches the library when NOT to use them.

## What changed from v5

- **Media Decision Engine** — routes every visual moment to the simplest sufficient medium.
- **3D Experience Director** — evaluates whether 3D is justified or rejected.
- **Frame Sequence Director** — complete scroll-scrubbed frame sequence pipeline.
- **Camera Director** — cinematography rules for web camera movement.
- **Blender → Web Pipeline** — optimization and export rules for 3D assets.
- **Asset DNA** — visual consistency system derived from Design DNA.
- **Performance Budget Engine** — per-project budgets for complex media.
- **Cinematic Anti-AI Fingerprints** — 13 new fingerprints for 3D, video, and generated asset clichés.
- **Mobile Media Strategy** — desktop and mobile may use different mediums.
- **Cinematic Accessibility** — every experience works without the cinematic part.
- **Three new QA gates**: Cinematic Purpose Gate, 3D Performance Gate, Frame Sequence Gate.

## What did NOT change

Everything from v5 (authenticity gate, divider policy, motion grammar, composition restraint, typography-first, rest zones) and v4 (color, typography intelligence, source intelligence, scroll, 3D intelligence, backend) remains fully in force.

## Start here

1. Read `START_HERE_V6.md`.

## Core rule

> The medium follows the idea. The simplest medium capable of delivering the intended experience is always correct.
