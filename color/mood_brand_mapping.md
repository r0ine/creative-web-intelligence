# Mood → Palette Strategy Mapping

This is a decision aid, not a stereotype table.

| Desired feeling | Strong starting direction | Often avoid |
|---|---|---|
| Precise / technical | cool or neutral graphite + one clear accent | many competing neon colors |
| Editorial / cultural | off-white or near-black + typography-led restrained accent | default SaaS blue gradients |
| Premium / material | low-chroma neutrals + material-derived accent | automatic black+gold cliché |
| Organic / calm | warm neutrals + analogous earth/green/blue family | saturated green everywhere |
| Playful | controlled triadic/split-complementary with clear dominance | equal-area rainbow palette |
| Industrial | neutral/cool surfaces + signal color | random futuristic cyan |
| Fashion | strong contrast + one unusual signature hue | generic beige-only minimalism |
| 3D product | DOM neutrals derived from model/material + selective accent light | independent UI and scene palettes |
| Data-heavy | neutral foundation + semantic categorical colors | decorative palette that conflicts with data semantics |
| Experimental | unusual relationships allowed, but preserve hierarchy and readable states | effect-first chaos |
