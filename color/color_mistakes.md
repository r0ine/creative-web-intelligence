# Color Mistakes / Anti-Slop Checks

Flag these patterns:

1. Purple→blue gradient selected only because the product contains AI.
2. Black+gold selected only because the prompt says "luxury".
3. Green selected only because a company mentions sustainability.
4. All palette colors have similar saturation and visual weight.
5. Accent covers so much area it is no longer an accent.
6. Muted text fails readability.
7. Hover/focus depends only on tiny hue changes.
8. Success and brand accent are indistinguishable.
9. Dark mode is pure black + glowing cards with no surface hierarchy.
10. Light mode is beige + serif + sage only to look "human designed".
11. Gradients are added to empty areas without a compositional job.
12. 3D lighting introduces unrelated cyan/purple colors into a restrained DOM palette.
13. Every section invents a new accent.
14. Color is used to encode state without labels/icons/shapes.
15. Categorical data colors are chosen for beauty before separability.
16. A palette is evaluated only as equal swatches rather than on real screen area.
17. Low opacity is used as the only method to create hierarchy.
18. White text is placed on bright accents without contrast validation.
19. The same accent is used for primary CTA, destructive action and selection.
20. Brand color is forced into every component.
