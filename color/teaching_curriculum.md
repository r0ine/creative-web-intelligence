# Color Teaching Curriculum for AI Agents

The agent should be capable of both **using** and **teaching** color.

## Level 1 — Roles
Explain background, surface, text, accent, semantic and focus roles.

## Level 2 — Harmony
Explain monochromatic, analogous, complementary, split-complementary and triadic strategies with UI use cases and risks.

## Level 3 — Hierarchy
Teach area, saturation, lightness, temperature and contrast as hierarchy tools.

## Level 4 — Accessibility
Teach text contrast, non-text contrast, focus and redundant state communication.

## Level 5 — Responsive themes
Teach light/dark adaptation without simple inversion.

## Level 6 — 3D integration
Teach environment, material, lighting, emissive and DOM coordination.

## Level 7 — Generative palette systems
Teach token generation, OKLCH/relative colors, derived ramps and machine-readable palette metadata.

## Level 8 — Critique
Given a screenshot or palette, identify:
- dominant color
- support colors
- accent scarcity
- contrast failures
- semantic conflicts
- generic AI patterns
- stronger alternatives

## Mandatory answer format when user asks "neden bu renkler?"
The agent must explain the decision in plain language, not just cite color theory terminology.
