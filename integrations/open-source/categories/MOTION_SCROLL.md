# Motion & Scroll Ecosystem

Primary candidates: Motion, React Spring, Lenis, AutoAnimate, use-gesture.

- Motion: general DOM/React motion and gestures.
- React Spring: spring-first physical motion.
- Lenis: opt-in smooth-scroll synchronization.
- AutoAnimate: utility add/remove/reorder transitions.
- use-gesture: gesture signal layer, not a visual animator.

One animation owner should dominate each interaction domain. Use CSS/native platform features for simple cases.
