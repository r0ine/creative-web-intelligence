# 3D Rendering Ecosystem

## Default path
Three.js is the core renderer. React projects can layer React Three Fiber and Drei. React Postprocessing/postprocessing is optional.

## Alternatives
- PixiJS: fundamentally 2D interactive graphics.
- Babylon.js: engine-heavy WebGPU/WebXR/3D use cases.
- OGL: small shader-first WebGL experiences.

## Specialist extensions
- three-mesh-bvh: spatial queries/raycast acceleration.
- React Three Rapier: actual physics.
- Troika: optimized WebGL/Three text/graphics.
- React Three Offscreen: experimental worker rendering.

Never pick an engine by popularity alone. Pick by scene complexity, authoring model, performance budget and team framework.
