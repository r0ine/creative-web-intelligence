# Creative Component Sources

Permissive sources currently catalogued: Motion Primitives, Magic UI, UI Layouts, Kokonut UI.

Use them as a **capability mine**:
1. identify the underlying effect/interaction,
2. compare with internal recipes,
3. ingest only if meaningfully new,
4. normalize API + tokens + accessibility,
5. record provenance.

React Bits is excluded from source ingestion under current Commons Clause policy.
