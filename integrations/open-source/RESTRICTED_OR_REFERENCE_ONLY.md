# Restricted / Reference-Only Sources

The research system may study these projects, but the library must not blindly vendor them.

## React Bits
Current repository metadata describes **MIT + Commons Clause**. Project-level use may be permitted by its terms, but redistribution as a competing component/effects library is blocked by local policy. Store only references/analysis unless terms change.

## LYGIA
Shader files declare a Prosperity License and the project offers a commercial-license path. Do not copy shader functions into this distributable library by default. Use it as conceptual research unless appropriate rights are obtained.

## Theatre Studio
Theatre core is Apache-2.0 while Studio is AGPL-3.0. Keep Studio development-only and preserve the licensing boundary.

## Unknown licenses
Any registry entry marked `verify-at-install` must be re-checked before vendoring or redistribution. Dependency use should still be reviewed.
