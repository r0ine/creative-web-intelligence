## New directors
Font, Composition, Motion, 3D Art, Reference Analyzer 2.0, Recipe Composer, Visual QA.

## Important limitation
Public indexing does not equal full visual review. Instagram/YouTube items that cannot be fully inspected must remain INDEXED or NEEDS_CAPTURE.

## v2.1 external open-source integration layer

Adds a curated registry and license-aware selection policy for 3D/rendering, motion/scroll, UI primitives, creative components, route transitions, creative coding, authoring/devtools, assets and agent knowledge. This layer intentionally avoids blindly vendoring upstream code.

Selection principle: **internal primitive -> small compatible external primitive -> larger engine only when justified**.
