# V3.1 Overview

v3.1 is a production-hardening expansion. It does not replace the creative decision system in v2/v3; it makes the implementation and QA layers stricter.

## Acceptance philosophy

A polished visual result does not compensate for exposed secrets, broken authorization, unreadable typography, motion sickness, inaccessible controls, data-loss risk, weak error handling, or a mobile layout that simply scales the desktop version.
