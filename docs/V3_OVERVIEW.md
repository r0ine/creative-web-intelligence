# V3 Overview

## Decision stack

`Input/Reference -> Reference Intake -> Design DNA -> Typography -> Color -> Composition -> Scroll/Motion -> optional 3D -> Backend Decision -> Data/API Design -> Full‑Stack Composer -> Implementation -> Visual/Fidelity QA -> Backend/Security QA -> Performance/Accessibility Gate`

## Added machine-readable coverage

- 120 advanced scroll recipes (in addition to v2.2's 100)
- 72 motion token combinations
- 120 backend recipes
- 72 reference-recreation recipes
- 60 full-stack integration recipes
- 96 v3 QA checks
- 48 media/runtime recipes
- viewport and fidelity schemas

## V3 acceptance rule

A project fails v3 if any of these are true:

- the design looks like a generic AI template,
- scroll animation exists without a narrative or spatial reason,
- mobile is merely a scaled desktop composition,
- a reference recreation is judged only by “looks similar” without measured viewport comparison,
- backend code is added without data/auth/runtime need,
- secrets, auth, database, upload or webhook behavior lacks explicit security rules,
- beautiful visuals are allowed to hide accessibility/performance failures.
