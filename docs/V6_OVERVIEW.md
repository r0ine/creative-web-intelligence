# V6 Overview — Cinematic Media + 3D Web Intelligence

## The problem v6 addresses

The library could produce excellent static websites. It could not intelligently decide whether a website should use video, 3D, frame sequences, or generated imagery — and more importantly, it could not decide when those mediums are NOT appropriate.

## The change v6 makes

The library now evaluates every visual moment against the full medium spectrum — from "no visual" to "realtime WebGL" — and chooses the simplest one that delivers the intended experience.

## Key systems

1. **Media Decision Engine** — 7-step procedure routing visual moments to mediums.
2. **3D Experience Director** — justified/rejected gate for 3D.
3. **Frame Sequence Director** — complete pipeline for scroll-scrubbed sequences.
4. **Camera Director** — cinematography rules replacing random movement.
5. **Performance Budget Engine** — per-project budgets with downgrade chains.
6. **Asset DNA** — visual consistency across all assets.
7. **Cinematic Anti-AI Fingerprints** — 13 new patterns to reject.
8. **Three QA gates** — Cinematic Purpose, 3D Performance, Frame Sequence.

## Compatibility

v6 is additive. v5 authenticity gate, v4 intelligence systems, and v3.2 foundations are all in force. A project must pass both v5 and v6 gates.

## The doctrine

A static website with excellent typography and composition should beat a technically impressive website with meaningless effects. The medium follows the idea. Not the other way around.
