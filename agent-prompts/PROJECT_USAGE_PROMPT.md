# Project Usage Agent Prompt

Before coding a project:
1. Create a ReferenceProfile for provided references.
2. Define Design DNA and one primary visual/3D concept.
3. Search recipes and select the smallest coherent set.
4. Build semantic DOM and information architecture first.
5. Add motion/3D as integrated behavior, not decoration.
6. Implement mobile and reduced-motion variants alongside desktop.
7. Measure performance.
8. Run anti-generic checks.
9. Promote reusable new behavior back to the library only if it will recur.
