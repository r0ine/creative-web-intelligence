# Rights-Safe Recreation

The engine may reproduce **visible layout/motion behavior using new code** from references supplied by the user.

Do not:

- extract/copy private or proprietary source code,
- bypass access controls,
- redistribute paid templates/components without permission,
- copy protected logos, photography, video, copywriting or licensed fonts when rights are not established.

When rights are unclear, use neutral placeholders while matching geometry, hierarchy, interaction and animation behavior. If the user owns/provides the assets, wire those assets into the implementation.
