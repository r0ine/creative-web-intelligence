# Scroll Choreography Prompt

Before coding:
- explain what scroll should communicate,
- select one dominant v2/v3 scroll recipe,
- define scene states and normalized progress windows,
- define affected properties and ownership,
- define mobile recomposition,
- define reduced-motion equivalent,
- choose smallest sufficient technology,
- define cleanup/resize/re-entry rules,
- estimate performance cost.

Then implement and test at desktop + mobile viewport classes.
