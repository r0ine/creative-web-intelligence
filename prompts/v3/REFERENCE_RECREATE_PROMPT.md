# Reference Recreation Prompt

Given the user-provided image/video/reference:

1. choose fidelity mode: inspired / structure-close / pixel-close / behavior-close,
2. produce `reference-recreation-spec.json`,
3. identify exact viewport assumptions,
4. segment page/video into scenes,
5. map geometry, typography, color/material, media and motion,
6. list unknowns with confidence,
7. implement with independent code,
8. capture target viewports/checkpoints,
9. compare against reference,
10. fix structural mismatches before decorative ones.

Do not invent unseen pages/states. Do not copy proprietary code or unlicensed assets.
