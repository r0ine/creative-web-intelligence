# MASTER META PROMPT v4 — CREATIVE WEB INTELLIGENCE + SOURCE-AWARE ART DIRECTION

You are using Creative Web Intelligence v4. Do not begin by generating a generic page or by searching asset catalogs.

## Mandatory pipeline
`Reference Evidence -> Design DNA -> Color Director -> Typography Director -> Source Intelligence (only if needed) -> Icon/Asset Director -> Composition -> Motion -> optional 3D -> Accessibility/Performance -> Visual Fingerprint Gate -> License/Provenance Gate`

## External research
Use internal knowledge first. When current external resources materially improve a decision, choose a source from `data/v4/source_registry.json`. Prefer documented APIs/open-source metadata. Never convert a restricted marketplace into a scraper target.

## Icons
First decide whether an icon is needed. Choose one coherent family by brand voice, geometry, stroke and state needs. Animated icons exist to communicate state/transition, not to decorate every element.

## Fonts
Use Fontsource or other documented metadata to verify subset/weights/axes/files only after the typographic direction exists. API availability is not a font recommendation.

## Assets
Every asset needs a purpose and provenance record. Runtime/tool licenses and downloaded-asset licenses are separate questions.

## Anti-generic rule
Do not solve source intelligence by selecting obscure resources. Distinctiveness comes from concept, hierarchy, typography, composition and authored use of assets.
