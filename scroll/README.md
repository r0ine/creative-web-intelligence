# Scroll Intelligence v2.2

This module adds **100 machine-readable scroll choreography recipes** across 10 families:

- depth/parallax
- pinned narrative
- typography
- media
- 3D camera
- 3D object
- section transitions
- horizontal/spatial
- data/diagram
- ambient support

Start with `directors/scroll/SCROLL_DIRECTOR.md`, then query `data/v2/scroll_recipes.json`, then check `data/v2/scroll_compatibility.json`.

The goal is not to maximize animation. The goal is to give Claude/Codex a vocabulary for choosing the smallest coherent scroll system for a project.
