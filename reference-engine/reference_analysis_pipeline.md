# Reference Analysis Pipeline

1. Register the source and confidence.
2. Capture observable layout proportions, typography roles, color relationships, spacing/rhythm and media role.
3. Map trigger → response for each motion/interaction.
4. For 3D: record camera, object role, scene state, lighting/material, shader/postFX only when visible or technically confirmed.
5. Separate `observed`, `inferred`, and `proposed`.
6. For inspiration work, translate observations into reusable capabilities/recipes. For a user-requested faithful recreation, preserve observed composition and behavior with independent code and permitted assets.
7. Add mobile/reduced-motion/performance notes.
8. Run semantic duplicate detection against existing recipes.
