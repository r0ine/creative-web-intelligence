# Section Separation & Divider Policy v3.2

## Default

A new section does not automatically deserve a horizontal line.

## Separation ladder

Try in this order:

1. whitespace/rhythm
2. compositional alignment change
3. typography scale or label change
4. background/surface value shift
5. media or spatial handoff
6. controlled overlap/bleed
7. divider/border if an actual information boundary still needs reinforcement

## Divider is justified when

- rows need scannable boundaries;
- a table/list requires structure;
- metadata groups would otherwise merge;
- the brand language intentionally uses rules as a recurring editorial device;
- a section boundary needs semantic reinforcement after spacing/composition are insufficient.

## Divider spam fingerprint

Flag when most consecutive sections use the same `1px rgba(...)` border with no semantic reason, especially when paired with identical container widths and reveal animations.

## Cardification rule

Do not put every content block into rounded bordered cards. First attempt open layout, rows, columns, editorial grouping, typographic grouping or media-led composition. Cards should imply containment, selection, action, state or repeated units.
