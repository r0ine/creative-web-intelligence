# License & Provenance Gate

No external asset enters a production build until these are known:

1. source and canonical URL
2. asset/family identifier
3. license name + link (or explicit `needs-review`)
4. commercial use status
5. attribution requirement
6. redistribution/bundling rule
7. modification rule if relevant
8. date checked

`needs-review` means **do not bundle yet**. The AI must not convert uncertainty into permission.
