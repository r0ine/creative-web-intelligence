# Restricted / Manual Sources

## IconScout
Do not build a generic scraper. Use manual selection or an official API integration only when the project has the appropriate agreement/credentials. Do not vendor the Design Asset Library into this repository.

## unDraw
The public license permits broad project usage but explicitly restricts automated linking/embedding/scraping/search/download integrations without consent and forbids using the assets for AI/ML training. Treat it as manual selection unless permission/integration terms change.

## Mixed-license catalogs
SVG Repo and similar aggregators require per-asset license review. Never infer the license from the catalog homepage.
