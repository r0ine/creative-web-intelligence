# Start Here — v3.2

For a new creative website, do not begin by choosing a trendy font, a purple gradient or a `fadeUp()` helper.

## Required sequence

1. Read the brief and identify the content hierarchy and brand tension.
2. Create a Design DNA profile: quiet/expressive, editorial/product, technical/organic, premium/utilitarian, warm/cool, dense/airy.
3. Run Color Director v3.2. If using Wada, select by measured relationship and project fit, then adapt for screen roles and contrast.
4. Run Typography Director v3.2 before polishing layout. Define display/body/UI/data roles, language coverage, metrics, wrapping and fallback behavior.
5. Compose the page without motion. If hierarchy fails while static, motion is not allowed to rescue it.
6. Choose one motion grammar and at most one secondary grammar. Do not default to bottom-to-top entrance reveals.
7. Use dividers only after checking spacing, type hierarchy, background shift, media, alignment and rhythm as alternatives.
8. Run accessibility/performance checks.
9. Run Visual Fingerprint Gate. If repeated AI-coded motifs dominate, recompose rather than adding more decoration.

The intended output is a coherent visual language with reasons, not a collection of effects.
