# Research Methodology

This library is intentionally evidence-layered.

## Confidence states

- **VERIFIED** — primary/official page or directly accessible source confirms the claim.
- **INDEXED** — search-engine indexing exposes enough text to verify a limited claim, but the full social post/video was not directly playable here.
- **SYNTHESIZED** — a general design/engineering principle derived from multiple references or professional practice; not attributed to one creator.
- **VERIFIED+SYNTHESIZED** — grounded in a primary source and translated into a reusable library rule.
- **NEEDS_CAPTURE** — user provided a visual reference but frame-level analysis requires an uploaded screenshot/screen recording.

## Rules

1. Never claim to have watched an inaccessible Instagram Reel end-to-end.
2. Never invent exact fonts, hex colors, spacing values, easing curves, 3D tools or shaders from a reference that was not visually/technically confirmed.
3. Store observed fact separately from the reusable principle derived from it.
4. Treat awards galleries as discovery/watchlists; deep behavior analysis requires the actual site or a captured video.
5. Prefer primary technical docs for implementation constraints.
6. Treat creator tips as examples and heuristics, not universal laws.
7. Every catalog record should eventually include source, confidence, performance cost, mobile strategy and compatibility.
8. A future ingestion agent should append rather than overwrite existing research and should deduplicate by URL + semantic similarity.
