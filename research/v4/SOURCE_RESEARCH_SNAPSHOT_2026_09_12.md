# v4 Source Research Snapshot — 2026-09-12

Verified public/documented findings used for this release:

- Iconify public API supports icon search, collection browsing and icon-data/SVG queries. Iconify framework and API code have their own open-source licenses; icon-set licenses remain per collection.
- Iconify explorer currently exposes hundreds of thousands of icons across 200+ open-source sets.
- Line-MD: 1,218 icons, MIT, 24 grid; short render/transition animation is the core design behavior. Repository guidance discourages attention-stealing/expensive looping animation.
- Tabler Icons: MIT, 24x24 grid, 2px default stroke, 6k+ icons.
- Fontsource provides a public read-only API for font metadata, subsets, weights/styles, variable axes and package versions.
- IconScout offers official API/integration terms, but its design asset library must not be mirrored or treated as an unrestricted dataset.
- SVG Repo is mixed-license; individual asset licensing must be checked.
- unDraw allows broad end-product use but explicitly restricts automated scraping/search/download integrations without consent and AI/ML training use.
- LottieFiles exposes open developer tooling/runtimes and formats; downloaded animation rights remain a separate asset-license question.
- Rive runtimes are MIT-licensed; .riv project assets are separate from runtime licensing.

This file stores research conclusions, not copies of third-party asset catalogs.
