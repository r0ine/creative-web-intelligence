# V3.2 Visual Direction Gate

Release status: PASS / PASS-WITH-NOTES / FAIL.

## Color blockers

- palette source/provenance is misrepresented
- historical Wada HEX is treated as exact printed truth without conversion context
- required body text has insufficient contrast
- four source colors are used as four equal accents without role logic
- dark mode is a mechanical inversion

## Typography blockers

- required glyphs/scripts missing
- font choice has no role/voice/metric rationale
- heading composition collapses at a supported viewport
- fallback causes destructive layout shift
- display face is used for long copy against readability evidence
- multiple families exist only to look "designed"

## Motion blockers

- universal fade-up helper dominates sections
- mechanical stagger repeats throughout page
- motion hides or delays essential content unnecessarily
- reduced-motion variant absent for substantial movement
- no rest ranges in a long motion-heavy page

## Composition blockers

- divider repeated as the only separation method
- almost all content cardified without containment/action reason
- static layout lacks hierarchy and depends on animation for interest

## Final test

Capture representative viewports with motion disabled. The site must still look authored. Then review motion separately to confirm it adds continuity or emphasis rather than generic polish.
