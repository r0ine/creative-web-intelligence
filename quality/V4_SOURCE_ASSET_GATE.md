# V4 Source + Asset Quality Gate

A build fails this gate if:
- restricted-source automation was used without an approved integration path;
- an external asset lacks provenance/license state;
- icons are chosen before the interface/brand voice is defined;
- more than two icon families appear on one surface without justification;
- animation loops exist without continuous-state meaning;
- font API results are treated as aesthetic ranking;
- a marketplace/illustration catalog is mirrored into the repository;
- third-party art becomes the concept instead of supporting it.
