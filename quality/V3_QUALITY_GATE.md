# V3 Quality Gate

A project is reviewed in independent dimensions so visual polish cannot hide technical failures.

## Creative
- typography
- color/material
- composition
- originality / anti-template
- responsive recomposition

## Motion
- narrative purpose
- timeline coherence
- mobile behavior
- reduced motion
- focus/keyboard safety
- resize/cleanup

## Reference fidelity (when requested)
- structure
- geometry
- typography metrics
- media crop
- color/material
- motion state/timing

## Backend (when present)
- auth/authz
- validation
- database integrity
- error contract
- rate limiting/abuse
- secrets
- uploads/webhooks
- observability
- test coverage

## Runtime
- performance budget
- accessibility
- SEO/metadata when relevant
- error/loading/offline-ish states as required
- responsive viewport matrix

Critical failures cannot be averaged away by a high visual score.
