# V3 tools

- `compose_v3_spec.py` — creates a skeleton full-stack build spec.
- `validate_v3_library.py` — validates v3 JSON files/counts/basic IDs.
- `extract_reference_frames.ps1` — optional FFmpeg-based frame extraction for user-supplied videos.
- `new_reference_workspace.ps1` — creates a reference-analysis workspace.

The tools do not replace agent vision/reasoning. They organize evidence and make iteration reproducible.
