# Reference Recreation Director v3

Do not start implementation before producing a reference profile.

Required outputs:
- source inventory
- viewport assumptions
- section map
- geometry map
- typography map
- color/material roles
- asset map
- motion timeline when video exists
- unknowns/confidence
- fidelity mode
- rights-safe substitutions if needed

If the user requests “1:1”, interpret it as a measurable target, not permission to copy proprietary code/assets.
