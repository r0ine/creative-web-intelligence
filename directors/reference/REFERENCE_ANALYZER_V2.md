# REFERENCE ANALYZER 2.0

Do not say “inspired by X” and copy surface styling. Convert references into structured evidence.

For each reference capture:
- source + date + evidence status
- typography roles and character
- palette roles and contrast strategy
- grid, focal axis, negative space, section rhythm
- motion triggers, timing, easing character, persistence
- 3D: camera, light, materials, world, scene states
- DOM/WebGL synchronization
- interaction trigger -> response mapping
- mobile behavior if observable
- performance implications
- signature concept
- reusable lessons
- DO NOT COPY list (logo, artwork, brand assets, exact composition)

Evidence states: VERIFIED, INDEXED, SYNTHESIZED, NEEDS_CAPTURE. Never upgrade evidence silently.
