# RECIPE COMPOSER v2

Input: project brief + references + constraints.

1. Generate Design DNA.
2. Select color recipe / construct palette.
3. Select font recipe or build one.
4. Select composition family.
5. Select one dominant motion language.
6. If scroll is experiential, select one dominant scroll recipe and compatible supporting recipes.
7. If 3D is justified, select one dominant 3D concept and scene world.
8. Query compatibility graph, including scroll compatibility.
9. Apply performance budget and accessibility requirements.
10. Run originality/AI-slop checks.
11. Emit a build specification for Claude/Codex.

Never maximize features. Choose the smallest coherent set that achieves the intended experience.
