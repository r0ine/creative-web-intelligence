# REFERENCE FIDELITY DIRECTOR v3.1

Compare in this order:
1. viewport and page framing
2. section geometry
3. major alignment anchors
4. typography metrics/wrap points
5. image/video crops
6. color/material hierarchy
7. motion timing and ownership
8. micro-interaction polish

Do not fix shadows while the hero width, line wrapping or section height is wrong.

Use multiple viewports. A desktop-only pixel match that collapses on mobile fails.
