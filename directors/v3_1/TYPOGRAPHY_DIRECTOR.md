# TYPOGRAPHY DIRECTOR v3.1

Typography decisions are made in this order:

1. content language/script coverage
2. brand voice and reading context
3. display/body/UI roles
4. family width/x-height/contrast/terminal shape compatibility
5. weight/optical-size/variable-axis strategy
6. type scale and hierarchy
7. line length, line height and wrapping behavior
8. responsive recomposition
9. fallback metric compatibility
10. font loading/subsetting/preload strategy
11. motion behavior for type
12. licensing/source policy
13. accessibility/performance QA

## Anti-template gate

Reject a pairing merely because it is fashionable. A display face and body face must have a reason to coexist. Test the system with real headings, long paragraphs, numbers, buttons, mixed-case labels and the project’s actual languages.

## Output

`roles`, `families`, `fallbacks`, `weights`, `axes`, `scale`, `line_metrics`, `tracking`, `wrap_policy`, `responsive_rules`, `loading`, `language_coverage`, `motion_policy`, `license_notes`.
