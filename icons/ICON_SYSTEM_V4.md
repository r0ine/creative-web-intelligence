# Icon System v4

## Core principle
An icon system is a typographic and geometric system. Consistency beats catalog size.

### Define tokens
- `icon-size-xs/sm/md/lg`
- visual stroke density
- optical baseline offset
- fill/outline policy
- active/disabled/error state behavior
- motion policy

### Pair with typography
A 16px icon beside 14px text may look larger than a 20px icon beside 18px text depending on negative space. Evaluate apparent mass, not only CSS dimensions.

### Navigation
Text-only navigation is valid. Add icons only when scanning speed or spatial memory materially improves.

### CTA
Do not put an arrow on every button. Directional icons should communicate direction/continuation.
