# Icon & Asset Fingerprint Gate v4

Score 0-3 each:
- icon before every text label
- same generic outline family across unrelated brand moments
- Sparkles/Brain/Robot icon shorthand for AI
- Shield/Lock shorthand repeated for trust/security
- decorative animated icon loops
- mixed outline weights/families
- stock illustration with no narrative role
- generic floating 3D object
- Lottie inserted only to make a section move
- external asset palette fighting the site palette
- missing asset provenance/license

A high score is not fixed by choosing a rarer icon pack. Re-author the communication and asset strategy.
