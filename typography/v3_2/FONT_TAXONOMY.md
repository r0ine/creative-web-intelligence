# Font Taxonomy v3.2 — Beyond Serif/Sans

A useful font taxonomy describes visual behavior and reading role, not only broad category.

## Form families

- old-style serif
- transitional serif
- didone/high-contrast serif
- humanist/flared serif
- slab serif
- display/decorative serif
- grotesk sans
- neo-grotesk sans
- humanist sans
- geometric sans
- industrial/engineered sans
- rounded sans
- condensed/compact family
- extended/wide family
- monospaced
- semi-mono/technical hybrid
- experimental/display

## Morphology dimensions

Profile each candidate on normalized 0..1 axes where practical:

- apparent x-height
- cap-height impression
- width / condensation
- stroke contrast
- aperture openness
- counter openness
- terminal sharpness vs softness
- geometric regularity
- humanist modulation
- roundness
- texture/rhythm density
- numeral distinction
- punctuation clarity
- display personality
- body readability
- UI compactness

These scores are descriptive, not objective beauty scores.

## Context dimensions

Separate morphology from context fit:

- editorial
- interface
- product
- technical/data
- cultural/arts
- luxury
- youth/playful
- institutional
- architectural/industrial
- immersive/experimental

A font can be strong in several contexts. Do not map one industry to one font.
